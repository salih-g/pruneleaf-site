Common questions

Why does Pruneleaf ask for access to folders?

Pruneleaf runs in the App Sandbox, so it can only see folders you allow. It needs ~/.claude for Claude Code, Claude Desktop's data folder to clean the VM image and caches, and optionally ~/.claude.json to back up MCP server settings. Each folder opens already selected; click Grant Access.

Does Pruneleaf delete my files?

No. Everything you clean is moved to the Trash, so you can put it back from Finder. The space comes back when you empty the Trash.

It says Claude is running and won't clean.

Claude Desktop's files can only be moved while Claude Desktop is closed, and Claude Code's files while no Claude Code session is open. Quit them and Pruneleaf continues on its own.

Where is my backup stored?

In your private iCloud database under your Apple Account, encrypted on your Mac first. The developer has no servers and no access to it.

How do I restore on a new Mac or after a reinstall?

Install Pruneleaf, allow access to ~/.claude, then open Restore. If iCloud Keychain is on, your key arrives within a few minutes; otherwise enter your recovery key. Pick the Mac to restore from and review the files before you start.

I lost my recovery key.

If iCloud Keychain is on, open Pruneleaf › Backup › Recovery key › Show… on a Mac that still has the key and save it again. If no Mac has the key, the backup can't be decrypted. That is what keeps it private.

How do I delete my backup?

Open Pruneleaf › Backup › Delete This Mac's Backup, or remove Pruneleaf's data in System Settings › [your name] › iCloud › Storage.
